## 검색 회귀

대규모 노드가 500 item을 넘으면서 Gate B 평가기가 첫 페이지만 읽는 문제를
발견해 V4 검색에 `offset`, `has_more`, `next_offset`, 전체 item/document 수를
추가했다. 평가기는 모든 페이지를 순회한다.

- 36개 Gate B 모두 scored
- V4 recall 1.0000, legacy 정확구문 recall 0.3430
- 누적 원문 정독 필요 문서 24,647→11,375(53.85% 감소)
- T1/T2 기존 평가 fail 0
- 전체 회귀 208 passed, 1 skipped

V4 조회시간 합계는 확장 전보다 증가했으며, 현 구현은 페이지마다 전체 후보를
재구성한다. 다음 성능 단계에서는 SQL keyset pagination으로 바꿀 필요가 있다.
