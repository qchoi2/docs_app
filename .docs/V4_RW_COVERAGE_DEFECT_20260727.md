# 근본원인 규명 — RW 진술 추출·coverage 결함 (2026-07-27, Claude)

Gate B 부재형에서 드러난 "RW 진술 계열 부재정밀도 저조(조세 44%·환경 50%)"의 원인을
운영 DB(`cs_index/catalog.sqlite`) 직접 조회로 규명했다. 결론: **추출 범위 결함 + coverage
일괄 과표기**의 결합이다.

## 증거 1 — 진술 하위영역이 통째로 누락

RW `body_status='complete'`로 표시된 **934개** 문서 중, 해당 하위영역 item이 **0개**인 비율:

| 진술 하위영역 | item 0개 문서 | 전 코퍼스 총 item 수 |
|---|---|---|
| **RW.IP*(지재)** | **917 / 934 = 98%** | **29개** (10만 item 중) |
| RW.LABOR*(노무) | 787 / 934 = 84% | 246개 |
| RW.ENVIRON*(환경) | 644 / 934 = 68% | 797개 |
| RW.TAX*(조세) | 344 / 934 = 36% | 1,969개 |

지재·노무·환경·조세 진술은 거의 모든 M&A 계약에 존재한다. 특히 **지재 진술은 10만 item
전체에서 29개뿐** — 사실상 추출이 안 됐다. taxonomy에는 `RW.IP.OWNERSHIP/VALIDITY/
NO_INFRINGEMENT/LICENSES/...` 노드가 갖춰져 있으므로 **분류체계 문제가 아니라 추출 문제**다.

## 증거 2 — thinness가 아니라 하위영역 선택적 누락

잘 추출된 문서(RW item 16개 이상, **667개**)만 따로 봐도:
- **IP item 0개: 647 / 667 = 97%**
- LABOR item 0개: 521 / 667 = 78%

즉 item을 풍부히 뽑은 문서에서도 **지재·노무 진술은 조직적으로 빠진다.** 추출기가
권한·공시·조세·환경 진술은 잡고 지재·노무는 건너뛰는 패턴이다. (단순히 적게 뽑은 게 아님.)

## 증거 3 — coverage가 하위영역 검증 없이 일괄 complete

RW coverage 행 962개 중 **933개가 동일 문구 "V4-2 본문 검수 완료"**로 `complete` 표기.
문서·하위영역별로 "이 진술이 추출됐나 / present=false로 확인됐나"를 검증한 흔적이 없다.
= **complete 도장이 실제 추출 완전성과 무관**하다.

## 왜 false absence가 되는가 (연결)

부재 판정(`search_clause_absence`)은 (i) body_status=complete + (ii) 해당 taxonomy item 없음
→ `confirmed_absent`. RW는 (i)이 항상 참(일괄 도장)인데 (ii)가 추출 누락으로 참이 되므로,
**진술이 원문에 있어도 "없음"으로 확정**한다. Gate B 실측(조세 44%·환경 50% 정밀도)이
이 메커니즘의 직접 증거이며, IP·노무는 미측정이나 누락률(98%·84%)로 보아 정밀도가 훨씬 낮을 것이다.

## 권고

**즉시(재추출 불요) — 잘못된 답 차단:**
1. `search_clause_absence`에서 **family=RW(진술) 질의는 `confirmed_absent`를 반환하지 말고
   전부 `needs_review`로 강등**한다(사유: `rw_coverage_unverified`). RW coverage='complete'는
   현재 신뢰할 수 없다. (특약·선행조건 family는 Gate B에서 90%대이므로 유지 가능.)

**근본(재추출 + coverage 감사 재설계) — 전량 확장 전 필수:**
2. RW 진술 재추출 시 **표준 진술 하위영역 체크리스트**(지재·노무·환경·조세·소송·조직/권한·
   재무제표·자산·계약·인허가·개인정보·부패방지 등)를 강제해, 각 영역을 item으로 추출하거나
   `present=false`+근거로 명시하게 한다. 추출 입력에 매도인 진술 조항 전문이 포함되는지 확인.
3. `body_status='complete'`는 **하위영역별 완전성 감사 통과 시에만** 부여한다(일괄 도장 폐지).
   누락 영역이 있으면 `partial`.
4. 이 교정을 **전량 확장보다 우선**한다. 현재 300+300 확장 배치도 동일 결함을 이미 복제했다
   (누락률이 전 배치에 걸쳐 나타남). 지금 더 확장하면 결함이 전 코퍼스로 확대된다.
